PRIVATE HELPERS (define these first — all other functions use them):

1. `_gini(arr: np.ndarray) -> float` — standard 4-line numpy Gini:
   ```python
   arr = np.sort(arr.astype(float))
   n = len(arr)
   if n == 0 or arr.sum() == 0: return 0.0
   idx = np.arange(1, n + 1)
   return float((2 * (idx * arr).sum()) / (n * arr.sum()) - (n + 1) / n)
   ```

2. `_enp(weights: np.ndarray) -> float` — ENP = 1/sum(s_i^2):
   ```python
   total = weights.sum()
   if total == 0: return 0.0
   shares = weights / total
   return float(1.0 / (shares ** 2).sum())
   ```

3. `_get_final_tallies(results_df: pd.DataFrame) -> pd.DataFrame` — last VOTE_CAST row per proposal:
   ```python
   vote_df = results_df[results_df['event_type'] == 'VOTE_CAST']
   return (vote_df.groupby('proposal_id').last()
           [['legacy_for','legacy_against','signals_for','signals_against']]
           .reset_index())
   ```

4. `_add_signals_weight_column(vote_df: pd.DataFrame) -> pd.DataFrame` — adds `signals_w` column:
   ```python
   vote_df = vote_df.copy()
   vote_df['signals_w'] = np.vectorize(compute_signals_weight)(
       vote_df['weight'].values,
       vote_df['lock_duration_days'].fillna(0.0).values,
   )
   return vote_df
   ```

METRIC FUNCTIONS — implement all 8 non-timing metrics:

**compute_flip_rate(results_df)** (METR-01):
- Extract final tallies using `_get_final_tallies`
- `legacy_pass = final['legacy_for'] > final['legacy_against']` (strict: tie = Fail)
- `signals_pass = final['signals_for'] > final['signals_against']`
- `flipped = (legacy_pass != signals_pass)`
- per_proposal = dict(zip(final['proposal_id'], flipped.tolist()))
- aggregate = float(flipped.mean())
- Return FlipRateResult

**compute_gini(results_df)** (METR-02):
- Filter VOTE_CAST rows, add signals_w column via `_add_signals_weight_column`
- Legacy: `_gini(vote_df['weight'].values)`
- Signals: `_gini(vote_df['signals_w'].values)`
- Return GiniResult

Note: Gini computed over participating voters only (voting power distribution, not total holder distribution). Document this in docstring.

**compute_participation_rate(results_df)** (METR-03):
- Filter VOTE_CAST rows
- total_unique_voters = vote_df['voter'].nunique()
- Per proposal: voters_per_proposal = vote_df.groupby('proposal_id')['voter'].nunique()
- per_proposal = (voters_per_proposal / total_unique_voters).to_dict()
- aggregate = float(np.mean(list(per_proposal.values())))
- Return ParticipationResult
- Guard: if total_unique_voters == 0, return all zeros

**compute_enp(results_df)** (METR-04):
- Filter VOTE_CAST rows, filter FOR/AGAINST only (NOT ABSTAIN — per pitfall 5)
- Add signals_w column
- For each proposal_id group: compute `_enp(group['weight'].values)` and `_enp(group['signals_w'].values)`
- Return ENPResult

**compute_nakamoto_coefficient(results_df)** (METR-05):
- Filter VOTE_CAST rows, filter FOR/AGAINST only
- Add signals_w column
- For each proposal, sort weights descending, cumsum until > 50% of total, return index+1
- If no votes, return 0
- Return NakamotoResult with per-proposal dicts

Helper `_nakamoto(weights: np.ndarray) -> int`:
```python
if len(weights) == 0 or weights.sum() == 0: return 0
sorted_w = np.sort(weights)[::-1]
cumsum = np.cumsum(sorted_w)
threshold = 0.5 * sorted_w.sum()
idx = np.searchsorted(cumsum, threshold, side='left')
return int(idx + 1)
```

**compute_margin_shift(results_df)** (METR-06):
- Extract final tallies
- Legacy margin: `(legacy_for - legacy_against) / (legacy_for + legacy_against)` — guard division by zero with np.nan
- Signals margin: same formula with signals columns
- shift = signals_margin - legacy_margin
- per_proposal = dict(zip(proposal_ids, shifts))
- aggregate_mean = float(np.nanmean(list(shift.values())))
- aggregate_std = float(np.nanstd(list(shift.values())))
- Return MarginShiftResult

**compute_transition_matrix(results_df)** (METR-07):
- Extract final tallies
- legacy_pass = final['legacy_for'] > final['legacy_against']  (tie = Fail, strict)
- signals_pass = final['signals_for'] > final['signals_against']
- pp = (legacy_pass & signals_pass).sum()
- pf = (legacy_pass & ~signals_pass).sum()
- fp = (~legacy_pass & signals_pass).sum()
- ff = (~legacy_pass & ~signals_pass).sum()
- total = pp + pf + fp + ff
- counts = ((int(pp), int(pf)), (int(fp), int(ff)))
- proportions = counts normalized by total (or all zeros if total == 0)
- Return TransitionMatrix

**compute_top_k_concentration(results_df)** (METR-10):
- Filter VOTE_CAST rows, filter FOR/AGAINST only
- Add signals_w column
- K_VALUES = [1, 5, 10] (hardcoded per locked decision)
- For each k in K_VALUES, for each proposal: sort voter weights descending, sum top-k, divide by total
- Edge case: if k >= num_voters, return 1.0 (all voting power captured)
- Return TopKConcentrationResult(legacy={k: {pid: share}}, signals={k: {pid: share}})

IMPORTANT: For all division operations, guard against zero denominator — return `np.nan` rather than raising or returning 0.

IMPORTANT: The `per_proposal` fields in all dataclasses use `dict[str, T]`, NOT `pd.Series`. This avoids the frozen dataclass + Series equality conflict (Pitfall 4 in research).

IMPORTANT: No import from `cadCAD` or `backtesting.simulation` anywhere in this file.

```python
def _merge_windows(vote_df: pd.DataFrame, windows_df: pd.DataFrame) -> pd.DataFrame:
    """Merge start_block/end_block into vote rows from windows_df."""
    return vote_df.merge(
        windows_df[['proposal_id', 'start_block', 'end_block']],
        on='proposal_id',
        how='left',
    )
```

Add private helper `_compute_lockin_fraction(proposal_df, regime) -> float`:
```python
def _compute_lockin_fraction(proposal_df: pd.DataFrame, regime: str) -> float:
    rows = proposal_df.sort_values('block_number').reset_index(drop=True)
    start = float(rows['start_block'].iloc[0])
    end = float(rows['end_block'].iloc[0])
    window = end - start
    if window <= 0 or len(rows) == 0:
        return float('nan')
    w_col = 'weight' if regime == 'legacy' else 'signals_w'
    for_col = 'legacy_for' if regime == 'legacy' else 'signals_for'
    against_col = 'legacy_against' if regime == 'legacy' else 'signals_against'
    total_cast = rows[w_col].sum()
    cumulative = 0.0
    for _, row in rows.iterrows():
        cumulative += row[w_col]
        remaining = total_cast - cumulative
        net = row[for_col] - row[against_col]
        if abs(net) > remaining:
            fraction = (row['block_number'] - start) / window
            return float(np.clip(fraction, 0.0, 1.0))
    return 1.0  # never locked in before all votes cast
```

Note: `_compute_lockin_fraction` reads cumulative tally columns (`legacy_for`, `signals_for`) for the `net` calculation — these are the running totals, so the last value naturally reflects the cumulative state at each timestep. This is the correct use of the cumulative columns.

**compute_late_vote_share(results_df, windows_df)** (METR-08):
- Filter VOTE_CAST rows from results_df
- Add signals_w via `_add_signals_weight_column`

- is_late = block_number >= late_threshold
- For each proposal: late_l = sum of weight where is_late; total_l = sum of weight

- Return LateVoteShareResult

Note: Late-vote share is weighted by voting power (not voter count) — sum of weight/signals_w, not count of late rows.
