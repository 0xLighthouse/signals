Create `apps/simulations/src/backtesting/report.py` as a new module. Follow the OO matplotlib API pattern from `plots.py` (no pyplot — use `Figure()` directly). Set `matplotlib.use('Agg')` as the FIRST matplotlib call, same as plots.py.

**ReportResult dataclass (frozen):**
- `output_dir: str` — absolute path to output directory
- `saved_paths: list[str]` — list of all saved file paths

**_nan_to_none_extended(obj):**
- Extended version of sweep.py's `_nan_to_none` that ALSO handles `np.integer` types (np.int64, np.int32) by casting to `int()`. This is CRITICAL because `summary_df['cell_id']` is `np.int64` which is NOT a subclass of Python `int` and will cause `json.dumps()` to raise `TypeError`.
- Handle `np.floating` defensively as well (cast to float, check NaN/Inf).
- Recursively process dicts and lists/tuples.

**_METRIC_CMAPS dict:**
Map metric column names to appropriate colormaps:
- Unsigned metrics (`flip_rate`, `participation_rate`): `'Blues'`
- Concentration metrics where lower is better (`gini_legacy`, `gini_signals`): `'RdYlGn_r'` (reversed — low=green)
- Concentration metrics where higher is better (`enp_legacy_mean`, `enp_signals_mean`, `nakamoto_legacy_mean`, `nakamoto_signals_mean`): `'RdYlGn'`
- Signed metrics (`margin_shift_mean`): `'RdYlGn'`

**_plot_metric_heatmap(summary_df, metric, row_axis, col_axis, cmap, title=None) -> Figure:**
- Filter `df[df['failed'] == False]` before pivoting (exclude failed cells).
- Use `pd.pivot_table(values=metric, index=row_axis, columns=col_axis, aggfunc='mean')` to create 2D matrix.
- Create `Figure(figsize=(8, 6))`, add subplot.
- MANDATORY: `ax.imshow(data, origin='lower', cmap=cmap, aspect='auto')` — origin='lower' is the documented requirement (REPT-01). Default 'upper' flips rows.
- REPT-07: Annotate each cell with `ax.text(j, i, f'{val:.3f}', ...)`. Skip NaN cells. Use contrasting text color (white on dark cells, black on light cells) based on value relative to colormap range.
- Set tick labels from pivot index/columns. Rotate x-labels 45 degrees.
- Add colorbar.
- Return Figure.

**_build_summary_dict(df) -> dict:**
- Build a summary dict from summary_df for JSON export.
- Include: total_cells, failed_cells count, metric aggregates (mean of each metric column across non-failed cells), per-metric min/max/mean.

**generate_sweep_report(sweep_result, *, best_n=3, worst_n=3, ranking_metric='flip_rate', row_axis='curve_type', col_axis='alpha') -> ReportResult:**
- REPT-08 orchestrator. Accept SweepResult, produce structured output.
- REPT-04: Create subdirectories: `heatmaps/`, `detail/`, `timing_sensitivity/` under `sweep_result.output_dir`.
- REPT-02: Export `sweep_results.csv` via `summary_df.to_csv(path, index=False)`.
- REPT-03: Export `sweep_summary.json` via `json.dump(_nan_to_none_extended(summary), f, indent=2)`.
- REPT-01 + REPT-07: Generate one heatmap per metric in `_METRIC_CMAPS`. Save to `heatmaps/{metric}.png` at dpi=300, bbox_inches='tight'.
- Return ReportResult with output_dir and list of all saved paths.
- Note: Detail plots (REPT-06) and composite figure (REPT-05) will be added in Plan 02.

Import `matplotlib` and set backend at top of file (before any Figure import), same as plots.py pattern. Import from `matplotlib.figure import Figure`.
