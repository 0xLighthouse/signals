**SweepConfig dataclass:**
```python
@dataclass
class SweepConfig:
    curve_types: list[str]
    alphas: list[float]           # maps to pareto_alpha in generate_scenario
    lock_profiles: list[dict]     # [{'short': 30, 'long': 365}, ...]
    allocation_strategies: list[str]
    max_workers: int              # required, no auto-detection
    cell_timeout_seconds: int = 120
    base: dict = field(default_factory=dict)  # [base] TOML section passthrough
```

**SweepCell dataclass:**
```python
@dataclass
class SweepCell:
    cell_id: int
    curve_type: str
    alpha: float
    lock_profile: dict           # {'short': int, 'long': int}
    allocation_strategy: str
```

**SweepResult dataclass:**
```python
@dataclass
class SweepResult:
    config: SweepConfig
    summary_df: pd.DataFrame     # one row per cell
    failed_cells: list[int]      # cell_ids that failed/timed out
    output_dir: str
```

**_enumerate_cells(config: SweepConfig) -> list[SweepCell]:**
Use `itertools.product(config.curve_types, config.alphas, config.lock_profiles, config.allocation_strategies)` to produce the cartesian product. Assign sequential `cell_id` starting from 0.

**load_sweep_config(path: str | pathlib.Path) -> SweepConfig:**
Use `tomllib.load()` to parse the TOML file. Extract `data['sweep']` for grid axes and `data.get('base', {})` for base config. `max_workers` is required (KeyError if missing). `allocation_strategies` defaults to `['uniform_fraction']` if not specified. `cell_timeout_seconds` defaults to 120.

**_make_output_dir(base_dir: str = './output') -> pathlib.Path:**
Follow pipeline.py pattern: `timestamp = datetime.datetime.now().strftime('%Y%m%d_%H%M%S')`, create `base_dir / timestamp`, resolve, mkdir.

**_nan_to_none(obj: Any) -> Any:**
Copy from pipeline.py — recursively replace float('nan')/float('inf') with None for JSON export.

**_make_failed_row(cell: SweepCell) -> dict:**
Return a dict with cell grid params + `failed=True` + NaN for all metric columns.

**__all__:** Export `SweepConfig`, `SweepCell`, `SweepResult`, `load_sweep_config`.

**Lock profile mapping design decision:** TOML lock profiles `{short, long}` map to `l_max_days=long` in `generate_scenario()`. The `short` key is captured in `summary_df` as `lock_profile_short` for analysis but does not map to a `generate_scenario` parameter (there is no `l_min_days` param). The `lock_profile` string param defaults to `'independent'` and can optionally be specified in [base] section. This is the simplest mapping that preserves the TOML structure from CONTEXT.md while working with the existing factory API.
