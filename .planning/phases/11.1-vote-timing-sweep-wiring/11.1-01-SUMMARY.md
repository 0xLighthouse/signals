## What Was Built

### Task 1: sweep.py wiring

All changes mirrored the existing mc_dist pattern exactly:

1. **Top-level import** — `from backtesting.data.factory import VoteTimingConfig` added next to `AllocationDistribution` import
2. **SweepConfig.vote_timings** — `vote_timings: list[VoteTimingConfig] | None = None` field added after `mc_dists`
3. **SweepCell.vote_timing** — `vote_timing: VoteTimingConfig | None = None` field added after `mc_dist`
4. **_enumerate_cells()** — `vote_timing_values = config.vote_timings if config.vote_timings else [None]` added; itertools.product extended with `vote_timing_values` axis; loop unpacks `vote_timing` and passes to `SweepCell(vote_timing=vote_timing)`
5. **_make_failed_row()** — `'vote_timing_label': repr(cell.vote_timing) if cell.vote_timing is not None else None` added after `mc_dist_label`
6. **_run_cell()** — kwargs injection `if cell.vote_timing is not None: kwargs['vote_timing'] = cell.vote_timing` added; `vote_timing_label` added to return dict
7. **load_sweep_config()** — Parses `[[sweep.vote_timings]]` TOML table array; docstring updated with TOML example; `vote_timings=vote_timings` passed to SweepConfig constructor
8. **run_sweep() config.json export** — `'vote_timings': [repr(t) for t in config.vote_timings] if config.vote_timings else None` added to config_dict

### Task 2: test_sweep.py tests

7 new test functions added in clearly labeled `MCAL-05` section:

- `test_enumerate_cells_with_vote_timings` — single vote_timing in axis produces 1 cell with correct vt instance
- `test_enumerate_cells_vote_timings_none_backward_compat` — None vote_timings produces 1 cell with vote_timing=None
- `test_enumerate_cells_vote_timings_cartesian` — 2 curve_types x 2 vote_timings = 4 cells cartesian product
- `test_make_failed_row_has_vote_timing_label` — schema consistency: label populated when set, None when not
- `test_swep07_toml_vote_timings` — TOML `[[sweep.vote_timings]]` table array parsed to VoteTimingConfig list
- `test_swep07_toml_no_vote_timings` — TOML without vote_timings results in vote_timings=None (backward compat)
- `test_mcal05_sweep_distinct_results` — Integration: 2 timing configs produce 2 rows with distinct vote_timing_label values

## Decisions Made

- VoteTimingConfig imported at module level (not deferred inside _run_cell) because factory.py is a leaf module — no circular dependency risk
- Used `[None]` sentinel for `vote_timing_values` when `config.vote_timings is None` — identical to mc_dists pattern, prevents TypeError from itertools.product receiving None
- vote_timing_label included in both _make_failed_row() and _run_cell() return dict for consistent DataFrame column schema
