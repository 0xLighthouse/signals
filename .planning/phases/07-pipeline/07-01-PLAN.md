Create `pipeline.py` as a single flat module in `apps/simulations/src/backtesting/`. Use ONLY stdlib imports (`tomllib`, `argparse`, `pathlib`, `json`, `datetime`, `dataclasses`, `warnings`, `math`) plus the existing backtesting modules. Zero new dependencies.

**`PipelineResult` dataclass (frozen=True):**
- `metrics: dict` — keyed by metric name (e.g., `'flip_rate'`, `'gini'`), values are `dataclasses.asdict()` dicts
- `plot_paths: list[str]` — absolute paths to all saved PNG files
- `output_dir: str` — absolute path to experiment output directory

**`_DEFAULTS` dict:**
```python
_DEFAULTS = {
    'data': {
        'n_voters': 200,
        'n_proposals': 30,
        'seed': 42,
        'stake_profile': 'pareto',
        'lock_profile': 'independent',
    },
    'output': {
        'dir': './output',
        'name': None,
    },
}
```

**`_resolve_config(config)` function:**
- If `config` is None: auto-discover `backtesting.toml` in CWD; if not found, use empty dict
- If `config` is str/Path: open with `tomllib.load()` (`'rb'` mode required)
- If `config` is dict: use directly
- Deep-merge user config over `_DEFAULTS` using a recursive `_deep_merge()` helper (NOT `dict.update()`)

**`_make_output_dir(cfg)` function:**
- Read `cfg['output']['dir']` and `cfg['output']['name']`
- If name is provided and non-empty: `output_base / name`
- If name is None/empty: `output_base / datetime.now().strftime('%Y%m%d_%H%M%S')`
- Resolve to absolute path early with `.resolve()`
- `mkdir(parents=True, exist_ok=True)`

**`run_pipeline(config=None, verbose=False)` function — the 4 stages:**

Stage 1 (Data): Call `generate_scenario()` with params from `cfg['data']`. Only pass keys that `generate_scenario` accepts. If verbose, print `'Generating data...'`.

Stage 2 (Simulation): Extract `windows_df` from `events_to_dataframe(events)` BEFORE running simulation (the `PROPOSAL_CREATED` rows with `proposal_id`, `start_block`, `end_block`). Then `run_backtest(events)` wrapped in `warnings.catch_warnings()` with `simplefilter('ignore')`. Then `build_results_dataframe(raw, events)`. If verbose, print `'Running simulation...'`.

Stage 3 (Metrics): Call all 10 `compute_*` functions. Store in a dict keyed by metric name. Use `dataclasses.asdict()` to convert each result to a plain dict. Apply `_nan_to_none()` recursively (converts `float('nan')` to `None` and handles nested dicts/lists). If verbose, print `'Computing metrics...'`.

Stage 4 (Plots): Call all 11 `plot_*` functions. For per-proposal plots (`plot_cumulative_vote_curve`, `plot_proposal_story`), iterate over ALL unique proposal_ids from the results_df. Save each figure with `fig.savefig(str(path), dpi=300, bbox_inches='tight')` then `fig.clf()` to release memory. Filenames: `flip_rate.png`, `margin_shift.png`, `transition_matrix.png`, `gini_comparison.png`, `top_k_comparison.png`, `enp_comparison.png`, `late_vote_share.png`, `lorenz_curve.png`, `lock_duration_histogram.png`, `cumulative_vote_{proposal_id}.png`, `proposal_story_{proposal_id}.png`. If verbose, print `'Plotting...'`.

After Stage 4: Save `metrics.json` to output dir with `json.dump(metrics_dict, f, indent=2)`. If verbose, print `'Done. Output: {out_dir}'`.

Return `PipelineResult(metrics=metrics_dict, plot_paths=[str(p) for p in all_paths], output_dir=str(out_dir))`.

**Error handling:** Wrap each stage in try/except. On failure, `raise RuntimeError(f'Pipeline stage "{stage_name}" failed: {e}') from e`. No silent failures.

**`_STARTER_TOML` template string** for `--init`:
```
# backtesting.toml — Signals backtesting configuration
# All values shown are defaults. Uncomment and edit as needed.

[data]
# n_voters = 200
# n_proposals = 30
# seed = 42
# stake_profile = "pareto"   # "pareto" | "uniform" | "bimodal"
# lock_profile = "independent"  # "correlated" | "inverse_correlated" | "independent" | "bimodal"

[output]
# dir = "./output"
# name = ""   # empty = auto-timestamp
```

**`_write_init_config()` function:** Write `_STARTER_TOML` to `Path.cwd() / 'backtesting.toml'`, print the path, and exit.

**`_parse_args(argv=None)` function:** argparse with:
- `--output` (default `'./output'`, metavar `DIR`)
- `--name` (default None, metavar `NAME`)
- `--config` (default None, metavar `PATH`)
- `--init` (action `store_true`)
- `-v`/`--verbose` (action `store_true`)
- `prog='python -m backtesting.pipeline'`

**`main(argv=None)` function:**
- Parse args
- If `--init`: call `_write_init_config()` and `sys.exit(0)`
- Build config dict: start with `--config` path if given, else None. Then overlay `output.dir` from `--output` and `output.name` from `--name` (only if explicitly provided by user).
- Call `run_pipeline(config=cfg, verbose=args.verbose)`

**`__main__.py`:** Minimal delegator:
```python
from backtesting.pipeline import main

if __name__ == '__main__':
    main()
```

IMPORTANT ANTI-PATTERNS TO AVOID:
- Do NOT import `matplotlib.pyplot` anywhere in pipeline.py — use `fig.savefig()` (OO API)
- Do NOT call `matplotlib.use()` — plots.py already sets Agg backend at import time
- Do NOT pass events list to metrics functions — they take `results_df` (and optionally `windows_df`)
- Do NOT use `dict.update()` for config merging — use recursive deep merge
- Do NOT forget to handle `float('nan')` before `json.dumps()` — use `_nan_to_none()`
- Do NOT forget `'rb'` mode for `tomllib.load()`
