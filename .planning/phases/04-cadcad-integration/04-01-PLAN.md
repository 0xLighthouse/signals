    **`policies.py`** — implement `policy_event_replay` exactly:
    ```python
    """Policy functions for cadCAD event-replay simulation."""
    from typing import Any

    def policy_event_replay(
        params: dict[str, Any],
        substep: int,
        state_history: list[dict[str, Any]],
        prev_state: dict[str, Any],
    ) -> dict[str, Any]:
        """Read the next event from params['event_stream'] by step index.

        Returns {'event': evt} where evt is the event record dict at
        index prev_state['step'], or None if step is past end of stream.
        """
        step = prev_state['step']
        stream = params['event_stream']
        evt = stream[step] if step < len(stream) else None
        return {'event': evt}
    ```

    **`sufs.py`** — implement `suf_step`, `suf_tallies`, and `PSUBS`:
    - Import: `import copy`, `from typing import Any`, `from backtesting.weighting.signals import compute_legacy_weight, compute_signals_weight`
    - Import `policy_event_replay` from `.policies` for PSUBS definition
    - `suf_step(params, substep, state_history, prev_state, policy_input) -> tuple[str, int]`: return `('step', prev_state['step'] + 1)`
    - `suf_tallies(params, substep, state_history, prev_state, policy_input) -> tuple[str, dict]`:
      - `evt = policy_input['event']`
      - `tallies = copy.deepcopy(prev_state['tallies'])` — CRITICAL: always deepcopy first (SIM-07)
      - If `evt is None`: return `('tallies', tallies)`
      - `etype = evt.get('event_type')`
      - PROPOSAL_CREATED: `tallies[evt['proposal_id']] = {'legacy': {'FOR': 0.0, 'AGAINST': 0.0, 'ABSTAIN': 0.0}, 'signals': {'FOR': 0.0, 'AGAINST': 0.0, 'ABSTAIN': 0.0}}`
      - VOTE_CAST: extract `pid`, `support`, `stake = float(evt.get('weight', 0.0))`, `lock_days = float(evt.get('lock_duration_days') or 0.0)`. If `pid in tallies and support in ('FOR', 'AGAINST', 'ABSTAIN')`: `tallies[pid]['legacy'][support] += compute_legacy_weight(stake)` and `tallies[pid]['signals'][support] += compute_signals_weight(stake, lock_days)`
      - PROPOSAL_FINALIZED: no change (deepcopy passthrough)
      - return `('tallies', tallies)`
    - `PSUBS = [{'policies': {'event_replay': policy_event_replay}, 'variables': {'step': suf_step, 'tallies': suf_tallies}}]`

    Do NOT import from cadCAD in policies.py or sufs.py — they must be pure Python importable without cadCAD side effects. cadCAD is wired in runner.py (Plan 02).
