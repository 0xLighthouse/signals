## Decisions Made

- `_nakamoto()` degenerate path returns `float(np.nan)` — same NaN-for-degenerate convention as `_gini()` and `_enp()`, ensuring downstream `np.nanmean` aggregation in sweep ignores degenerate cells rather than corrupting averages with 0
- TOML loader NOT modified for `mc_dists` — programmatic API is the only path per Phase 10.1 scope; TOML leaves `mc_dists=None` by default which is backward compatible
- `mc_dist_label` column added to both `_make_failed_row()` and `_run_cell()` success row to maintain schema alignment across all summary DataFrame rows
