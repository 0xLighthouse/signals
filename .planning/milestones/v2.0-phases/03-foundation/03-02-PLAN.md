<objective>
Build the synthetic event stream factory and data loader layer. The factory generates realistic Governor-compatible event streams with configurable voter counts, proposal counts, stake distributions, participation profiles, and lock durations. The loader converts events to a sorted DataFrame and validates referential integrity at load time (fail fast).

Purpose: Enable generation of credible synthetic DAO governance data for simulation without requiring real on-chain data, while ensuring the loader contract (Protocol) supports zero-cost swap to real data later.

Output: `backtesting/data/factory.py`, `backtesting/data/loader.py`, shared test fixtures, and full test coverage.
</objective>

       - Internal helpers (prefixed with `_`):
         - `_generate_stakes(n_voters, total_supply, profile, pareto_alpha=0.7, rng=None) -> np.ndarray` — Pareto(alpha=0.7) for 'pareto', equal for 'uniform', 10%/90% split for 'bimodal'. Always normalize to total_supply.
         - `_generate_participation_probs(n_voters, avg_rate=0.10, rng=None) -> np.ndarray` — Power-law: probs = 1/ranks^0.5, normalized to target avg, clipped [0.01, 0.95].
         - `_generate_vote_timing(n_votes, start_block, end_block, early_frac=0.30, mid_frac=0.40, rng=None) -> np.ndarray` — Tri-modal: early 0-20% of window, mid 30-70%, late 80-100%. Splits: 30% early, 40% mid, 30% late.
         - `_generate_contentiousness(rng) -> float` — Mixed: 20% FOR blowout, 20% AGAINST blowout, 40% competitive, 20% coin-flip (see RESEARCH.md).
         - `_generate_lock_durations(n_votes, stakes, profile, l_max_days=365, rng=None) -> np.ndarray` — 'correlated': higher stake = longer lock. 'independent': uniform random. 'bimodal': 30% short-term (0-30d), 70% long-term (180-365d).
       - Main function: `generate_scenario(n_voters=200, n_proposals=30, total_supply=1_000_000.0, avg_participation_rate=0.10, stake_profile='pareto', lock_profile='independent', pareto_alpha=0.7, l_max_days=365.0, proposal_window_blocks=50400, seed=None) -> list[GovernorEvent]`
         - Creates RNG from seed (None = random). All randomness flows through this single RNG.
         - Generates voter addresses as `f'0x{i:040x}'`
         - Generates stakes using `_generate_stakes`
         - For each proposal: create ProposalCreatedEvent (sequential block numbers with gaps), determine participating voters (Bernoulli per voter using participation probs), generate vote timing, determine support (FOR/AGAINST/ABSTAIN using contentiousness), generate lock durations, create VoteCastEvent for each participant, create ProposalFinalizedEvent after end_block.
         - CRITICAL: Enforce no double votes by tracking (proposal_id, voter) pairs during generation.
         - CRITICAL: All votes must fall within [start_block, end_block] of their proposal.
         - Return events sorted by block_number.
         - Add warning log if n_voters < 100 and stake_profile == 'pareto' (Gini may not reach 0.65).
       - Do NOT call lock_curve or compute_signals_weight in factory. Factory produces raw data only.

       - `events_to_dataframe(events: Sequence[GovernorEvent]) -> pd.DataFrame` — calls .model_dump() on each event, creates DataFrame, sorts by block_number, resets index.
       - `validate_event_stream(df: pd.DataFrame) -> list[str]` — returns list of error strings (empty = valid):
         (a) Votes on unknown proposals (proposal_id not in PROPOSAL_CREATED set)
         (b) Double votes (same voter + proposal_id appears >1 time)
         (c) Votes outside proposal window (block_number < start_block or > end_block)
       - `SyntheticLoader` class: __init__(events: Sequence[GovernorEvent]), load() -> pd.DataFrame. Calls events_to_dataframe then validate_event_stream. Raises ValueError if errors.
       - `ParquetLoader` class: __init__(path: str), load() -> pd.DataFrame. Reads parquet, runs validate_event_stream. Raises ValueError if errors. Add `column_mapping: dict | None = None` parameter for future use.
       - Both classes satisfy GovernorDataLoader Protocol structurally (no inheritance needed).
       - Add a docstring comment on the DataFrame noting that consumers must filter by event_type before accessing type-specific columns (NaN values in non-applicable fields).

    3. Update `src/backtesting/data/__init__.py` to re-export factory and loader public names.
