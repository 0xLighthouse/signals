from backtesting.weighting.signals import compute_signals_weight as _compute_signals_weight

**New frozen dataclasses:**

1. `AddressInfluence(frozen=True)`:
   - `per_voter: pd.DataFrame` — columns: `['voter', 'legacy_share', 'signals_share', 'counterfactual_share', 'delta']`
   - `median_lock_days: float` — the median lock duration used as counterfactual baseline

2. `TimingSensitivity(frozen=True)`:
   - `heatmap: pd.DataFrame` — 2D pivot table indexed by timing quantile, columns = lock quantile
   - `n_quantiles: int` — number of quantile bins used (default 4)

3. `SignificanceResult(frozen=True)`:
   - `statistic: float` — Mann-Whitney U statistic
   - `p_value: float` — two-sided p-value

4. `BootstrapCI(frozen=True)`:
   - `low: float` — lower bound of confidence interval
   - `high: float` — upper bound of confidence interval
   - `confidence_level: float` — the confidence level used (e.g. 0.95)

**New functions:**

1. `address_influence(results_df: pd.DataFrame, curve_type: str = 'sqrt') -> AddressInfluence`:
   - **CRITICAL: Use median lock duration as counterfactual baseline (ANAL-02), NOT raw legacy weight.**
   - Filter to VOTE_CAST rows, copy DataFrame.
   - Compute `median_lock = float(vote_df['lock_duration_days'].fillna(0.0).median())`.
   - Add `signals_w` column using `np.vectorize(_compute_signals_weight)(weight, lock_duration_days.fillna(0.0), curve_type)`.
   - Add `counterfactual_w` column using `np.vectorize(_compute_signals_weight)(weight, median_lock, curve_type)` — everyone at median lock.
   - Group by `'voter'`, aggregate:
     - `legacy_share = voter_weight_sum / total_legacy_weight`
     - `signals_share = voter_signals_w_sum / total_signals_w`
     - `counterfactual_share = voter_counterfactual_w_sum / total_counterfactual_w`
   - Compute `delta = signals_share - counterfactual_share` (NOT `signals_share - legacy_share`).
   - Handle zero-denominator with NaN guard (`total == 0 → share = np.nan`).
   - Document in docstring WHY median-lock is the correct baseline: "isolates the commitment signal by comparing actual lock duration to the typical (median) lock, rather than comparing to the absence of commitment."
   - Return `AddressInfluence(per_voter=per_voter_df, median_lock_days=median_lock)`.

2. `timing_sensitivity(results_df: pd.DataFrame, windows_df: pd.DataFrame, curve_type: str = 'sqrt', n_quantiles: int = 4) -> TimingSensitivity`:
   - Filter to VOTE_CAST rows, copy.
   - Merge `start_block`/`end_block` from `windows_df` on `proposal_id` (left join).
   - Compute `timing_frac = (block_number - start_block) / (end_block - start_block)`. Guard zero window with `np.where`.
   - Add `signals_w` column using vectorized `_compute_signals_weight`.
   - Compute `weight_ratio = signals_w / weight` — how much the signal amplifies/attenuates each vote.
   - Use `pd.qcut(timing_frac, q=n_quantiles, labels=[f'T{i+1}' for i in range(n_quantiles)], duplicates='drop')` for timing quantiles.
   - Use `pd.qcut(lock_duration_days.fillna(0.0), q=n_quantiles, labels=[f'L{i+1}' for i in range(n_quantiles)], duplicates='drop')` for lock quantiles.
   - Build `pivot_table(values='weight_ratio', index='timing_q', columns='lock_q', aggfunc='mean', observed=True)` — MUST pass `observed=True` to suppress pandas 2.x FutureWarning.
   - **CRITICAL: Return a 2D DataFrame, not a 1D Series. Shape should be approximately (n_quantiles, n_quantiles).**
   - Return `TimingSensitivity(heatmap=heatmap, n_quantiles=n_quantiles)`.

3. `influence_significance(group_a: np.ndarray, group_b: np.ndarray) -> SignificanceResult`:
   - Drop NaN values from both arrays.
   - If either array has fewer than 2 elements, return `SignificanceResult(statistic=np.nan, p_value=np.nan)`.
   - Call `_mannwhitneyu(group_a, group_b, alternative='two-sided')`.
   - Return `SignificanceResult(statistic=float(stat), p_value=float(pval))`.

4. `bootstrap_ci(values: np.ndarray, statistic=np.mean, confidence_level: float = 0.95, n_resamples: int = 999, random_state: int = 42) -> BootstrapCI`:
   - Drop NaN values.
   - If fewer than 2 values, return `BootstrapCI(low=np.nan, high=np.nan, confidence_level=confidence_level)`.
   - Call `_bootstrap((values,), statistic, confidence_level=confidence_level, n_resamples=n_resamples, random_state=random_state, method='percentile')`.
   - Return `BootstrapCI(low=float(res.confidence_interval.low), high=float(res.confidence_interval.high), confidence_level=confidence_level)`.
