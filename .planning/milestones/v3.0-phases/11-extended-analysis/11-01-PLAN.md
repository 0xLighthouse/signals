  <action>
Create `apps/simulations/src/backtesting/analysis.py` as a pure-function module following the metrics.py pattern. Module docstring must reference the NaN-for-degenerate-inputs convention.

**Imports:** `from __future__ import annotations`, `dataclasses`, `numpy`, `pandas`. Do NOT import from cadCAD or simulation modules.

**Frozen dataclasses:**

1. `MarginClassBreakdown(frozen=True)`:
   - `tight: int` — flip count where |legacy_margin| < 10%
   - `moderate: int` — flip count where 10% <= |legacy_margin| < 30%
   - `decisive: int` — flip count where |legacy_margin| >= 30%
   - `total_flips: int`

2. `VoterArchetypes(frozen=True)`:
   - `labels: pd.DataFrame` — DataFrame with columns `['voter', 'weight', 'archetype']` where archetype is one of `'retail'`, `'medium'`, `'whale'`
   - `counts: dict[str, int]` — count per archetype label

**Functions:**

1. `margin_class_breakdown(results_df: pd.DataFrame) -> MarginClassBreakdown`:
   - Filter to VOTE_CAST rows, get final tallies per proposal using groupby('proposal_id').last() on `['legacy_for', 'legacy_against', 'signals_for', 'signals_against']` columns (replicate the `_get_final_tallies` logic inline — do NOT import from metrics.py to keep analysis.py independent).
   - Determine flipped proposals: `legacy_pass != signals_pass` where pass = `for > against` (tie = fail).
   - If no flips, return all zeros.
   - For flipped proposals, compute legacy margin: `abs((legacy_for - legacy_against) / (legacy_for + legacy_against))`. Use `np.where(denom == 0, np.nan, ...)` for zero-denominator guard.
   - Bin with `pd.cut(margin_abs, bins=[0.0, 0.10, 0.30, 1.01], labels=['tight', 'moderate', 'decisive'], include_lowest=True)`.
   - Return counts via `value_counts()`.

2. `voter_archetypes(results_df: pd.DataFrame) -> VoterArchetypes`:
   - Filter to VOTE_CAST rows.
   - Group by `'voter'`, sum `'weight'` to get per-voter total stake.
   - Use `pd.qcut(stakes, q=3, labels=['retail', 'medium', 'whale'])` to assign archetype labels.
   - Handle edge case: if fewer than 3 unique voters, assign all as `'retail'`.
   - Handle duplicate bin edges from `pd.qcut` by catching `ValueError` and falling back to `pd.cut` with `q=3` or assigning all to same category.
   - Return `VoterArchetypes(labels=voter_df, counts=dict(voter_df['archetype'].value_counts()))`.

**Module-level `__all__`:** Export `MarginClassBreakdown`, `VoterArchetypes`, `margin_class_breakdown`, `voter_archetypes`. Plan 02 will extend this list.
