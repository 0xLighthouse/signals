# Creating a Signals Board

A Signals board can be created around a specific theme or purpose, allowing participants to submit initiatives in line with the chosen objective. The board will have an owner who has additional rights and responsibilities to administer the board. It is possible for a DAO to enact ownership functions as the result of a DAO vote, enabling decentralized and permissionless operation of the board.

The board is first deployed via the `SignalsFactory` contract, and additional configurations can be applied later. 

## Factory Deployment

Boards are created through the `SignalsFactory` contract:

```solidity
function create(BoardConfig calldata config)
    external
    payable
    returns (address)
```

### Returns

- `address` - The deployed Signals board contract address

### Event Emitted

```solidity
event BoardCreated(
    address indexed board,
    address indexed owner,
    Metadata boardMetadata
)
```

## Configuration Structure

The complete configuration is defined in the `BoardConfig` struct:

```solidity
struct BoardConfig {
    string version;
    Metadata boardMetadata;
    address owner;                                      // Board owner address
    address underlyingToken;                           // ERC20 token address
    AcceptanceCriteria acceptanceCriteria;             // Who can accept and threshold rules
    uint256 maxLockIntervals;                          // Max lock duration in intervals
    uint256 lockInterval;                              // Time unit for locks (seconds)
    uint256 decayCurveType;                           // 0=linear, 1=exponential
    uint256[] decayCurveParameters;                    // Curve params
    uint256 inactivityTimeout;                         // Seconds before initiative can expire
    ParticipantRequirements proposerRequirements;      // Who can propose
    ParticipantRequirements supporterRequirements;     // Who can support
    uint256 releaseLockDuration;                       // Timelock after acceptance
    uint256 boardOpenAt;                              // Unix timestamp for opening
    uint256 boardClosedAt;                            // Unix timestamp for closing
}
```

## Acceptance Criteria

The `AcceptanceCriteria` struct controls who can accept initiatives:

```solidity
struct AcceptanceCriteria {
    AcceptancePermissions permissions;    // Permissionless or OnlyOwner
    ThresholdOverride thresholdOverride;  // None or OnlyOwner
    uint256 thresholdPercentTotalSupplyWAD;  // % of total supply (in WAD)
    uint256 minThreshold;                    // Minimum fixed threshold
}
```

### Example Configurations

**Owner-controlled (default):**
```solidity
AcceptanceCriteria({
    permissions: AcceptancePermissions.OnlyOwner,
    thresholdOverride: ThresholdOverride.OnlyOwner,
    thresholdPercentTotalSupplyWAD: 0,
    minThreshold: 100_000 * 1e18
})
```

**Community-driven:**
```solidity
AcceptanceCriteria({
    permissions: AcceptancePermissions.Permissionless,
    thresholdOverride: ThresholdOverride.None,
    thresholdPercentTotalSupplyWAD: 5e16,  // 5%
    minThreshold: 50_000 * 1e18
})
```

## Deployment Process

```solidity
// 1. Deploy factory (or use existing)
SignalsFactory factory = new SignalsFactory(implementationAddress)

// 2. Create board configuration
ISignals.BoardConfig memory config = ISignals.BoardConfig({
    version: "1.0.0",
    boardMetadata: ISignals.Metadata({
        title: "Community Initiatives",
        body: "A board for community-driven proposals",
        attachments: new ISignals.Attachment[](0)
    }),
    owner: msg.sender,
    underlyingToken: governanceTokenAddress,
    acceptanceCriteria: ISignals.AcceptanceCriteria({
        permissions: ISignals.AcceptancePermissions.OnlyOwner,
        thresholdOverride: ISignals.ThresholdOverride.OnlyOwner,
        thresholdPercentTotalSupplyWAD: 0,
        minThreshold: 100_000 * 1e18
    }),
    maxLockIntervals: 365,
    lockInterval: 1 days,
    decayCurveType: 0,
    decayCurveParameters: new uint256[](1),
    inactivityTimeout: 60 days,
    proposerRequirements: IAuthorizer.ParticipantRequirements({
        minBalance: 10_000 * 1e18,
        minHoldingDuration: 0,
        minLockAmount: 0
    }),
    supporterRequirements: IAuthorizer.ParticipantRequirements({
        minBalance: 0,
        minHoldingDuration: 0,
        minLockAmount: 0
    }),
    releaseLockDuration: 0,
    boardOpenAt: block.timestamp,
    boardClosedAt: 0
});

// 3. Deploy board via factory
address boardAddress = factory.create(config)

// 4. Cast to Signals contract
Signals board = Signals(boardAddress)

// 5. Optional: Set incentives pool (BEFORE boardOpenAt)
board.setIncentivesPool(poolAddress, incentivesConfig)
```

## Post-Deployment Configuration

After deployment, the board owner can:

```solidity
// Update acceptance criteria
board.setAcceptanceCriteria(newCriteria)

// Update decay curve
board.setDecayCurve(curveType, parameters)

// Update board timing
board.setBoardOpenAt(newOpenTime)
board.setBoardClosedAt(newCloseTime)

// Set incentives (only before board opens)
board.setIncentivesPool(poolAddress, config)

// Emergency actions
board.closeBoard()   // Close board normally
board.cancelBoard()  // Cancel board (immediate redemption for all)
```
